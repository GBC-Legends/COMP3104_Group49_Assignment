COMP3104 - DevOps

This course teaches what DevOps is, and how it helps teams build software faster and work better together.
We learn how to use tools for automation, testing, and deployment, and get hands-on practice with real projects.

COMP3104 also covers version control, cloud services, and helps us understand how modern software is built and released.
By the end, we will know what a DevOps engineer does, and how DevOps is used in today’s tech world.
